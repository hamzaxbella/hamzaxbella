## Interactive drawing

The cutaway concept is inspired by [Bartosz Ciechanowski’s mechanical-watch explanation](https://ciechanow.ski/mechanical-watch/) and [Amit Patel’s interactive diagrams](https://www.redblobgames.com/). The illustration and implementation are original; their code and artwork are not copied.

The README contains a static preview linked to the interactive GitHub Pages site. The drawing presents selected public project details as conceptual layers, not a literal deployment diagram.
